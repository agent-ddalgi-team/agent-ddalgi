# agent-ddalgi

인공지능사관학교 14기 기업연계 프로젝트 — 거산케미칼 영업지원 AI 에이전트

## 브랜치 구조

- `main` — 검증이 끝난 코드만 올라갑니다
- `develop` — 통합 테스트용. 작업한 내용을 먼저 여기에 모읍니다
- 작업 브랜치 — 각자 작업할 때 만듭니다

## 작업 규칙

- 작업 브랜치는 `develop`에서 만듭니다. 작업이 끝나면 `develop`으로 Pull Request를 올려주세요.
- `develop`에서 동작을 확인한 뒤, 검증이 끝나면 `main`으로 머지합니다.
- `main`에는 직접 푸시하지 않습니다.
- 브랜치는 작업을 시작할 때 직접 만듭니다. 미리 만들어두지 않습니다.
- 브랜치 이름은 영어 소문자로 쓰고 단어는 하이픈으로 연결합니다.
  `feat/` 새 기능 · `fix/` 버그 수정 · `chore/` 설정 · `docs/` 문서
  예: `feat/agent-llm`, `fix/upload-error`
- Pull Request는 제가 확인한 뒤 머지합니다. 머지된 작업 브랜치는 삭제합니다.
- `contracts/` 안의 파일을 수정할 때는 팀에 먼저 알려주세요. 프론트·백엔드·에이전트 모두에 영향이 갑니다.
- 다른 사람이 작업 중인 파일을 고쳐야 하면 먼저 알려주세요.

## 주의사항

- **기업에서 받은 자료는 저장소에 올리지 않습니다.** 공유 문서함을 사용해 주세요.
- **API 키는 `.env` 파일에만 둡니다.** 코드에 직접 쓰지 마세요.

두 항목 모두 `.gitignore`에 등록되어 있습니다.
