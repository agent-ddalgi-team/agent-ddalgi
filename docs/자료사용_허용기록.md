## 3. 자료 보관 위치·사용 허용·정리 상태

- 가짜 자료: `fixtures/`, 가짜 입력 복사본 `private_runs/day1/agent_input.json`,
  가짜 자료 추출 결과 `private_runs/day1/agent_extract_01.json`(Git 제외).
- 실제 기업 자료: 사용·저장하지 않음. **사용 허용 미확인.**
- `.env`(API 키)와 `private_runs/`는 Git 제외 규칙 확인됨. 키 값은 이 문서에 기록하지 않음.
- 임시 저장 정리: 미실시(현재 `private_runs`에는 가짜 자료만 있음).

## 4. 허용을 받으면 갱신할 것

1. 위 1절 표의 '실제 기업 자료' 행에 항목별 허용 여부와 **확인자·시점**을 적는다.
2. 2절 체크리스트 항목을 체크한다.
3. 그 뒤에야 실제 기업 자료를 입력에 사용할 수 있다. 그 전까지는 가짜 테스트 자료만 쓴다.

허용 근거가 기록되기 전까지 R10과 '실제 기업 자료 검증'은 **미확인·미완료 상태를 유지한다.**
